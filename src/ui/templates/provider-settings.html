Activar fuentes del globo

El globo funciona sin claves. Cada clave activa una fuente adicional — pégala y se guardará en la configuración local de esta app; después el servidor se reiniciará. Las claves del servidor permanecen en este equipo; Google Maps y Cesium ion se ejecutan en el navegador y deben restringirse en cada proveedor.

ESC para cerrar

La clave de Google Maps activa el planeta fotorrealista; las demás fuentes se superponen sobre él.
